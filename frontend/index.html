Como interpretar as métricas?

Precision@K: proporção dos resultados recuperados que foram anotados como relevantes.

Recall@K: proporção dos trechos relevantes anotados que foram recuperados.

MRR: avalia a posição do primeiro resultado relevante em cada consulta.

Estes valores são a linha de base registrada no projeto, não uma leitura automática dos CSVs. Atualize-os após novos experimentos.

SOBRE O PROJETO

Uma plataforma experimental para RAG.

O ResearchAI Lab explora a recuperação de informação científica e a geração de respostas contextualizadas por modelos de linguagem.

Objetivos acadêmicos

  • Estudar a recuperação semântica de documentos.
  • Inspecionar as fontes usadas para responder perguntas.
  • Avaliar o Retriever com métricas de recuperação.
  • Comparar configurações de chunking e Top-K.
  • Investigar limitações e respostas sem evidência suficiente.

Arquitetura

Interface web→ FastAPI→ RAG Pipeline→ ChromaDB + Ollama

MINIGLOSSÁRIO

Termos e conceitos

RAG

Retrieval-Augmented Generation. Abordagem que recupera informações de uma base de documentos e as fornece ao modelo de linguagem para contextualizar a resposta.

Embedding

Representação numérica de um texto em um vetor. Textos com significados relacionados podem ficar próximos nesse espaço vetorial.

ChromaDB

Banco vetorial utilizado para armazenar documentos e embeddings e recuperar trechos semelhantes a uma consulta.

LLM

Large Language Model. Modelo de linguagem que gera texto a partir de instruções e contexto.

Chunk

Segmento de texto extraído de um documento. A divisão em chunks permite recuperar partes específicas em vez de enviar o PDF inteiro.

Top-K

Número de trechos retornados pela busca. Com Top-K igual a 3, o Retriever seleciona até três resultados.

Distância vetorial

Medida de diferença entre vetores. Na configuração atual, valores menores indicam maior proximidade segundo a métrica usada. Isso não garante relevância factual.

Ground Truth

Referência anotada manualmente que identifica quais trechos são relevantes para uma pergunta e permite avaliar a recuperação.

Alucinação

Quando o modelo produz uma afirmação incorreta ou sem sustentação suficiente nas evidências disponíveis.

NOTA METODOLÓGICA

Respostas verificáveis

Uma resposta fluente não é necessariamente correta. Compare as afirmações da IA com os trechos recuperados e com o documento original.
